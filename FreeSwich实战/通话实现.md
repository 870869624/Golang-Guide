# FreeSWITCH 通话实现详解

## 一、通话建立流程

### 1. 注册阶段
- **用户代理**(UA)向FreeSWITCH发送`REGISTER`请求
- 携带认证信息（用户名、密码、域）
- FreeSWITCH验证后返回`200 OK`确认

### 2. 呼叫发起阶段
- 主叫方发送`INVITE`请求至FreeSWITCH
- 包含目标号码及媒体能力协商信息
- FreeSWITCH根据拨号计划解析目标地址

### 3. 呼叫连接阶段
- FreeSWITCH向被叫方转发`INVITE`请求
- 被叫方响应`180 Ringing`表示正在振铃
- 被叫方接听后返回`200 OK`确认

### 4. 会话确认阶段
- 主叫方向被叫方发送`ACK`确认消息
- 双方建立RTP媒体流通道
- 通话正式开始

## 二、核心组件配置

### 1. 分机配置
```xml
<!-- directory/default/1008.xml -->
<user id="1008">
  <params>
    <param name="password" value="123456"/>
    <param name="vm-password" value="888"/>
  </params>
  <variables>
    <variable name="accountcode" value="1008"/>
    <variable name="user_context" value="default"/>
    <variable name="effective_caller_id_name" value="Extension 1008"/>
    <variable name="effective_caller_id_number" value="1008"/>
  </variables>
</user>
```

### 2. 拨号计划配置
```xml
<!-- dialplan/default/01_example_dialplan.xml -->
<extension name="Local_Extension">
  <condition field="destination_number" expression="^(10[0-9]{2})$">
    <action application="export" data="dialed_extension=$1"/>
    <action application="bridge" data="${sofia_contact(${dialed_extension}@${domain_name})}"/>
  </condition>
</extension>
```

### 3. SIP Profile 配置
```xml
<!-- sip_profiles/internal.xml -->
<profile name="internal">
  <param name="sip-ip" value="$${local_ip_v4}"/>
  <param name="sip-port" value="5060"/>
  <param name="ext-rtp-ip" value="auto-nat"/>
  <param name="ext-sip-ip" value="auto-nat"/>
  <param name="rtp-ip" value="$${local_ip_v4}"/>
  <param name="rtp-port" value="16384-32768"/>
  <param name="force-register-domain" value="$${domain}"/>
  <param name="accept-blind-reg" value="false"/>
  <param name="accept-blind-auth" value="false"/>
</profile>
```

## 三、媒体流处理

### 1. 媒体协商 (SDP)
- 通过SIP消息携带SDP信息进行媒体能力协商
- 包括音频/视频编解码器、IP地址、端口等信息
- 支持多种编解码格式（G.711, G.729, Opus等）

### 2. RTP传输模式
- **BYPASS模式**：媒体流直接在终端间传输，降低服务器负载
- **PROXY模式**：所有媒体流经过FreeSWITCH，便于录音、监控等

### 3. 编解码配置
```xml
<param name="codec-prefs" value="OPUS,G722,PCMU,PCMA,H264"/>
<param name="dtmf-type" value="rfc2833"/>
```

## 四、通话控制

### 1. DTMF信号处理
- RFC 2833：带内DTMF传输
- SIP INFO：带外DTMF传输
- NATIVE：设备原生DTMF

### 2. 呼叫保持与恢复
- 使用re-INVITE消息修改会话状态
- 支持音乐等待(MOH)功能

### 3. 呼叫转移
```xml
<action application="transfer" data="1009 XML default"/>
```

## 五、高级功能

### 1. 通话录音

```xml
<action application="record_session" data="/var/lib/freeswitch/recordings/${strftime(%Y-%m-%d-%H-%M-%S)}_${caller_id_number}_${destination_number}.wav"/>
```


### 3. 会议桥接
```xml
<action application="conference" data="myconf@default"/>
```

## 六、故障排查

### 1. 常见问题诊断
- 检查分机注册状态：`sofia status profile internal reg`
- 查看当前通话：`show calls`
- 查看拨号计划：`show dialplan`

### 2. 日志监控
- 启用SIP调试：`console loglevel 7`
- 查看详细日志：`fs_cli` 或 `/var/log/freeswitch/freeswitch.log`

### 3. 网络问题
- 检查防火墙设置（SIP端口5060，RTP端口范围）
- 验证NAT配置
- 使用Wireshark抓包分析SIP/RTP流量
